## 🔭 Featured Projects

### 🛡️ [Phishing URL Detector](https://github.com/safeer-zubair/phishing-detector)
End-to-end phishing URL detection web app.
- Trained on the PhiUSIIL dataset (~235k URLs, 56 features) with a leakage-aware pipeline: train-only TLD risk map, and the label-proxy feature `URLSimilarityIndex` explicitly excluded
- 25 lexical/structural features extracted from raw URLs with no network calls
- Compares Logistic Regression, Random Forest and gradient boosting models
- FastAPI backend + web frontend, with Google Safe Browsing API for a hybrid verdict

**Stack:** Python · scikit-learn · FastAPI · Jupyter
